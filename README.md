# 📊 HR Analytics Dashboard

An interactive HR Analytics Dashboard built using **Microsoft Power BI** to analyze employee demographics, attrition, job satisfaction, performance, and department-wise workforce distribution.

## 📸 Dashboard Preview

![HR Analytics Dashboard](images/dashboard.png)

## 🎯 Project Objectives

- Analyze employee attrition and retention.
- Monitor workforce demographics and age groups.
- Explore attrition by department, salary slab, and gender.
- Evaluate job satisfaction and employee performance.
- Support data-driven HR decision-making.

## 📈 Key Performance Indicators

| Metric | Value |
|---|---:|
| Total Employees | 406 |
| Active Employees | 322 |
| Attrition Count | 84 |
| Average Performance | 3.17 |
| Attrition Rate | 20.69% |
| Average Age | 28.94 |
| Average Experience | 5.23 years |

## 🔍 Dashboard Features

- Age-group filtering
- Department filtering
- Attrition by department
- Attrition by salary slab
- Job role and job satisfaction analysis
- Gender-based attrition analysis
- Experience-based attrition trends
- Department-wise employee distribution

## 🛠️ Tools & Technologies

- Microsoft Power BI
- DAX
- Power Query
- Data Cleaning
- Data Visualization
- HR Analytics

## 💡 Business Insights

- 84 employees have left the organization.
- The reported attrition rate is 20.69%.
- The dashboard enables comparisons across departments, salary slabs, age groups, and job roles.

## 🚀 How to Use

1. Download `HR_Analytics_Dashboard.pbix` from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Interact with the filters and visualizations to explore the data.
